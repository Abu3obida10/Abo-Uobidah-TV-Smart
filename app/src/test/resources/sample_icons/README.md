# عينات أيقونات للاختبار (محاكاة، ليست أيقونات تطبيقات حقيقية)

مولّدة برمجيًا بأشكال هندسية بسيطة ولا تحمل أي شعار أو علامة تجارية، وهي أصلية لهذا المشروع ويجوز استخدامها وتوزيعها بلا قيود.
تغطي أحجامًا (48 إلى 640 بكسل)، وبانرات بنسبة 16:9، وألوانًا فاتحة وداكنة، وأيقونة شفافة بإطار فقط.
الغرض: اختبار القص والتلوين وملء البطاقات والتباين في المحاكاة. **لا تثبت** أن أيقونات التطبيقات المثبتة فعلاً على التلفزيون تظهر صحيحة؛
اللانشر يقرأها وقت التشغيل من PackageManager (Base.kt وAppsActivity.kt)، واختبار الأيقونات الفعلية معلّق حتى تثبيت APK على الجهاز.
